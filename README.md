##  Featured Project

### SecureRISC

**Hardware-Assisted Secure RISC-V-Style Processor**

A 32-bit processor architecture implemented in Verilog with hardware-assisted
security mechanisms for instruction verification and memory protection.

**Highlights:**

-  Hardware instruction verification
-  Memory Protection Unit (MPU)
-  Illegal instruction detection
-  Unauthorized memory access blocking
-  RTL verification and security attack testing
-  GTKWave waveform analysis
-  Icarus Verilog simulation
-  GitHub Actions CI
-  v1.0.0 release

 **[View SecureRISC](https://github.com/mayursn-007/SecureRISC)**
